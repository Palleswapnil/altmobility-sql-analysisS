# Alt Mobility – Data Analyst Assignment (SQL Approach)

## Overview
This project analyzes customer orders and payments for Alt Mobility using SQL (via pandasql in Colab) and pandas for visualizations.

## Files
- `01_order_sales_analysis.sql` – SQL for Task 1
- `02_customer_analysis.sql` – SQL + pandas segmentation
- `03_payment_status_analysis.sql` – SQL for Task 3
- `04_order_details_report.sql` – SQL join of orders & payments
- `05_customer_retention_pandas.ipynb` – Retention chart (optional)
- `order_details_report.csv` – Exported order+payment report
- `retention_chart.png` – Customer retention line chart
- `summary.pdf` – Findings and recommendations

## Tasks Covered

### Task 1 – Order & Sales Analysis
- Counted orders by status
- Analyzed revenue from delivered orders

### Task 2 – Customer Analysis
- Repeat order behavior via SQL
- Segmentation via pandas (New, Returning, Loyal)

### Task 3 – Payment Status
- Payment success/failure analysis
- Flagged customers with repeated failed payments

### Task 4 – Order Details Report
- Merged order and payment data

### Task 5 – Customer Retention
- Used pandas to build cohort-based line chart

## Tools Used
- Google Colab
- pandasql
- pandas
